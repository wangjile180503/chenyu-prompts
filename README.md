# chenyu—prompts

将剧情、剧本或参考视频整理成可直接复制的竖排视频分镜提示词。技术名称及调用名：`chenyu-prompts`。

## 框架

- 生成段落内包含多个小镜头，默认每段不超过30秒，在完整事件或自然反应结束处衔接。
- 固定字段：镜号、开始时间、结束时间、时长、画面描述、叙事内容、景别、摄影机角度、摄影机运动、焦距与景深、光线、人声/音效/环境音、图像生成提示词、视频运动提示词。
- 默认中文分镜、英文图像与运动提示词，台词保持用户指定语言。
- 默认无背景音乐，保留明确要求的人声、动作音效与环境音。
- 继承参考素材的人物、服装、道具、场景和风格，检查轴线、人数、动作接续、道具状态和时间算术。
- 区分实测视频内容与生成设计，不把无法听到的声音或估计的镜头参数写成已验证事实。

默认服务于 Seedance 2.5 提示词工作流；不内置模型接口，不执行生成或上传。模型限制和素材引用语法须按实际提供的指南核实。

## 使用

将仓库中的 `SKILL.md` 和 `agents` 目录一起放入用户技能目录下的 `chenyu-prompts` 文件夹。设置了 `CODEX_HOME` 时使用其下的 `skills`；否则使用 `~/.codex/skills`。

```text
使用 $chenyu-prompts，根据这段剧情生成第一场的完整分镜。
每个生成段落不超过30秒，使用竖排字段，不加背景音乐。
```

```text
使用 $chenyu-prompts，分析我提供的视频并生成同框架的提示词。
先核对实际画面，保留人物和动作连续性，说明重新编排的时间轴。
```

```text
使用 $chenyu-prompts，只调整以下提示词的声音，不改变画面和时间。
修改后给我完整版本。
```

完整执行规则见 [SKILL.md](SKILL.md)，界面信息见 [agents/openai.yaml](agents/openai.yaml)。

## 素材与审核说明

本仓库只包含提示词工作方法，不包含参考影片、角色资产、私有剧本或原始模型指南。替换专名不等于素材已获授权，文本检查也不等于平台审核通过；本 Skill 不承诺“无版权问题”或“保证过审”。
